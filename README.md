# Credit Risk Analysis Using Python

## Project Overview

This project focuses on analyzing credit risk data to understand the factors associated with loan approval decisions and customer creditworthiness. The objective is to identify meaningful patterns in customers' financial profiles, repayment behavior, delinquency history, and existing credit facilities using Python and statistical techniques.

The analysis helps explore how different customer characteristics relate to approval categories and supports a data-driven approach to understanding credit risk.

## Objectives

* Understand the dataset structure and identify data quality issues.
* Perform data cleaning and preprocessing to prepare the dataset for analysis.
* Conduct Exploratory Data Analysis (EDA) to discover patterns and relationships.
* Create meaningful features to categorize missed payments and delinquency levels.
* Apply statistical tests to evaluate relationships between customer attributes and approval categories.
* Perform feature selection to identify potentially useful variables for further analysis.

## Tools and Technologies

* **Python:** Core programming and data analysis.
* **Pandas:** Data manipulation and preprocessing.
* **NumPy:** Numerical operations.
* **Matplotlib and Seaborn:** Data visualization.
* **SciPy:** Statistical hypothesis testing.
* **Statsmodels:** Variance Inflation Factor (VIF) analysis for multicollinearity assessment.

## Project Workflow

### 1. Data Cleaning

Examined data types, missing values, duplicate records, and data consistency to improve data quality and prepare the dataset for analysis.

### 2. Exploratory Data Analysis

Analyzed customer income, missed payments, delinquency history, employment tenure, credit history, and existing secured and unsecured credit facilities. Compared these characteristics across approval categories to identify patterns.

### 3. Feature Engineering

Created meaningful categorical features, including missed-payment levels and delinquency groups, to simplify interpretation and support statistical comparisons.

### 4. Statistical Analysis

Applied Chi-Square tests to examine associations between categorical variables and approval categories. Used statistical testing to evaluate relationships and interpret findings using p-values.

### 5. Feature Selection

Explored feature relevance and multicollinearity using statistical techniques, including VIF, to help identify suitable variables for potential predictive modeling.

## Key Findings

The analysis identified statistically significant associations between approval categories and repayment-related indicators, including total missed payments and recent delinquency levels. Differences across income groups and existing loan facilities were also explored.

These findings highlight the importance of repayment behavior and credit history when analyzing credit risk patterns. Statistical significance alone does not establish causation or guarantee predictive performance.

## Conclusion

This project demonstrates a structured data analytics workflow, from data preprocessing and exploratory analysis to feature engineering and statistical evaluation. It strengthens practical skills in Python, data visualization, hypothesis testing, and analytical interpretation while building a foundation for future credit risk classification and predictive modeling.
